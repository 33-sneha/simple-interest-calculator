Contributing
All contributions, bug reports, bug fixes,
documentation improvements, enhancements, and
ideas are welcome.
How to Contribute
1. Fork the repository.
2. Create a new branch for your change ( git
checkout -b feature/my-change ).
3. Make your changes and commit them with a clear
message.
4. Push your branch to your fork.
5. Open a pull request describing your change.
Reporting Bugs
If you find a bug, please open an issue that includes:
A clear description of the problem
Steps to reproduce it
Expected vs. actual behavior
Code Style
Keep Bash scripts POSIX-friendly where possible, and
add comments for any non-obvious logic.
